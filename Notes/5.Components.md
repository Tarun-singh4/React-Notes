React Components

We don't need to write everything in App.jsx.
We can create a components folder and store reusable components there.
We can import and use components inside App.jsx.

Example:

// components/Card.jsx
function Card() {
  return <h2>My Card</h2>;
}

export default Card;
// App.jsx
import Card from "./components/Card";

function App() {
  return <Card />;
}

export default App;

Remember: React components are written with a capital letter, like Card, and used as <Card />, not <card />.

JavaScript Expressions in JSX
We can use {} inside JSX to access JavaScript variables and expressions.
Variables must be declared before they are used.

Example:

const name = "Tarun";

function App() {
  return <h1>Hello, {name}!</h1>;
}

Output: Hello, Tarun!

Remember: {} lets us use JavaScript expressions inside JSX.
