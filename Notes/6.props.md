# React Props

### What are Props?

* Props means **properties**.
* Props are used to pass data from a parent component to a child component.
* They allow us to reuse the same component with different data.

### Example

**Card.jsx**

```jsx
function Card(props) {
  return <h2>{props.name}</h2>;
}

export default Card;
```

**App.jsx**

```jsx
import Card from "./Card";

function App() {
  return (
    <>
      <Card name="Tarun" />
      <Card name="Rahul" />
      <Card name="Aman" />
    </>
  );
}

export default App;
```

**Output:**

```text
Tarun
Rahul
Aman
```

The same `Card` component displays different names using props.

---

### 1. Passing a String

Strings are written inside quotation marks.

```jsx
<Card name="Tarun" />
```

Access it using:

```jsx
{props.name}
```

### 2. Passing a Number

Numbers are passed using `{}`.

```jsx
<Card age={21} />
```

Access it using:

```jsx
{props.age}
```

### 3. Passing an Image

We can pass an image URL as a string.

```jsx
<Card img="https://example.com/photo.jpg" />
```

Display the image using:

```jsx
<img src={props.img} alt="Profile" />
```

For a local image imported into `App.jsx`:

```jsx
import profile from "./assets/profile.png";

<Card img={profile} />
```

### 4. Passing an Array

Arrays are passed using `{}`.

```jsx
<Card skills={["HTML", "CSS", "JavaScript"]} />
```

Access the array using:

```jsx
{props.skills.map((skill, index) => (
  <p key={index}>{skill}</p>
))}
```

Here, `map()` loops through the array and displays each skill.

---

### Important Points

* **String:** `name="Tarun"`
* **Number:** `age={21}`
* **Image:** `img={profile}`
* **Array:** `skills={["HTML", "CSS"]}`
* Use `props.name`, `props.age`, etc., to access props.
* Props are read-only; a child component should not modify them directly.
* Props make components reusable with different data.
